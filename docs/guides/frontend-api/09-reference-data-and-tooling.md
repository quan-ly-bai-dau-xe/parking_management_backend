## 12. Details of Administrative Unit Endpoints (`Đơn vị hành chính`)

The Administrative Units module (`apps/core`) provides cascading, read-only location selectors for Vietnam's 3-tier administrative hierarchy (Provinces/Municipalities -> Districts/Urban Districts -> Wards/Communes). These endpoints serve dropdowns in customer and employee creation/edit dialogs.

### 12.1 Cascading Administrative Hierarchy Dropdowns

1. **Hierarchy Flow**:
   - `GET /api/v1/administrative/provinces/`: Select Province/City -> returns `id`, `code`, `name`.
   - `GET /api/v1/administrative/districts/?province_id=<id>`: Select District -> filtered by parent Province ID.
   - `GET /api/v1/administrative/wards/?district_id=<id>`: Select Ward -> filtered by parent District ID.
2. **Access Permissions**:
   - Allowed for authenticated `EMPLOYEE` and `MANAGER` roles via `[IsAuthenticated, IsEmployeeOrManager]`.
   - Unauthenticated requests receive HTTP `401 Unauthorized`.
   - `CUSTOMER` requests receive HTTP `403 Forbidden`.
3. **Response Characteristics**:
   - Bare JSON array of objects `[{"id": int, "code": str, "name": str}]`.
   - Deterministically sorted by `id ASC`.
   - Returns only active administrative records (`deleted_at IS NULL`).
   - If an integer ID is provided that does not exist in the database, returns an empty array `[]` with HTTP `200 OK`. If the parameter is missing or non-integer, returns HTTP `400 Bad Request`.

## 13. Automatically Generate Typed Client or Postman Collection

### 13.1 Automatically Generate TypeScript Types with `openapi-typescript`

The Frontend can automatically extract type-safe TypeScript interfaces for every Request, Response, and Schema directly from the `/api/schema/` endpoint:

```bash
# Run directly against running server or downloaded schema.yaml
npx --yes openapi-typescript@7.13.0 http://127.0.0.1:8000/api/schema/ -o src/types/api.d.ts
```

### 13.2 Import into Postman (Postman Collection Import)

1. Open Postman, select **Import** in the upper-left corner.
2. Select the **Link** tab and paste the URL: `http://127.0.0.1:8000/api/schema/`.
3. Click **Continue** and select **Import as API with a Collection**.
4. The full API catalog and request/response examples will synchronize automatically into Postman.
