# Security Policy

## Reporting a Vulnerability

We take the security of the `parking_management_backend` system seriously. Because this repository is **PUBLIC** on GitHub, **NEVER report potential security vulnerabilities through public GitHub Issues, public pull requests, or public discussions.**

### Exclusive Disclosure Channel: GitHub Private Vulnerability Reporting

All vulnerability disclosures must be submitted strictly and exclusively through GitHub's **Private Vulnerability Reporting** feature:

1. Navigate to the **Security** tab of this repository on GitHub:
   `https://github.com/quan-ly-bai-dau-xe/parking_management_backend/security`
2. Under the "Reporting" section in the left sidebar, click on **Advisories**, then click the **Report a vulnerability** button.
3. Complete the private advisory draft with comprehensive details:
   - **Type of vulnerability**: (e.g., Authentication bypass, SQL injection, Privilege escalation, PII exposure, Insecure Direct Object Reference).
   - **Reproduction steps**: Clear step-by-step instructions or a minimal Proof of Concept (PoC).
   - **Affected components**: Endpoints, serializers, models, or configuration files involved.
   - **Potential impact**: Assessment of severity and exploitability.
4. Submit the report. This establishes a private communication advisory visible only to the repository maintainers and the reporter.

> **CRITICAL REMINDER**:
> Public disclosure of vulnerabilities puts users and systems at immediate risk. Do not publish details or open public issues until a remediation patch has been reviewed and released by the Team Lead.
